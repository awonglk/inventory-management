Factory Inventory Management System

Full-stack application with Vue 3 frontend, Python FastAPI backend, and in-memory mock data (no database).

System Architecture

Tech Stack

Frontend

Vue 3.5 + Vite 8

Composition API with reactive refs and computed properties. Vite dev server with HMR on port 3000.

Backend

FastAPI + Python 3.12

RESTful API with automatic OpenAPI docs. Pydantic models for request/response validation.

Data Layer

JSON Files

In-memory mock data loaded from JSON files at startup. No database or persistence layer.

HTTP Client

Axios

Centralized API client with query parameter building and response handling.

Package Manager

npm + uv

npm for frontend dependencies, uv for Python virtual environment and backend packages.

CORS

FastAPI Middleware

Configured to allow all origins during development for frontend-backend communication.

Key Features

Filter System

Four global filters apply to all data views:

Time Period Warehouse Category Order Status

Views

Seven main application views:

  • Dashboard with KPI tiles
  • Inventory management
  • Order tracking
  • Demand forecasting
  • Backlog items
  • Spending analysis
  • Quarterly reports

API Endpoints

  • GET /api/inventory
  • GET /api/orders
  • GET /api/dashboard/summary
  • GET /api/demand
  • GET /api/backlog
  • GET /api/spending/summary
  • GET /api/spending/monthly
  • GET /api/spending/categories
  • GET /api/spending/transactions
  • POST /api/purchase-orders

Data Files

Core Data

  • inventory.json - Stock levels, SKUs, warehouses
  • orders.json - Customer orders and fulfillment
  • purchase_orders.json - Supplier orders

Analytics Data

  • demand_forecasts.json - Predicted demand trends
  • backlog_items.json - Delayed order items
  • spending.json - Cost analysis data
  • transactions.json - Recent transactions

Development Workflow

Starting the Application

# Terminal 1: Backend
cd server && uv run python main.py
# Terminal 2: Frontend
cd client && npm install && npm run dev

Backend runs on http://localhost:8001 with API docs at /docs

Frontend runs on http://localhost:3000

Reactivity Pattern

The application uses Vue 3's Composition API with a clear separation:

  • Raw data stored in refs (allOrders, inventoryItems)
  • Derived data in computed properties (filtering, aggregation, formatting)
  • Filter state managed via composables for cross-component sharing
  • API calls centralized in api.js for consistency
